# Sistema de Vendas — V1

Sistema web desenvolvido para cadastrar vendas, acompanhar o histórico de registros e visualizar indicadores atualizados dinamicamente.

##Funcionalidades

- Cadastro de vendas
- Registro do produto, categoria, quantidade e preço
- Cálculo automático do valor de cada venda
- Histórico de vendas
- Exclusão de vendas cadastradas
- Atualização automática dos indicadores após exclusões
- Cálculo do valor total das vendas
- Média das vendas
- Identificação da maior e da menor venda
- Produto mais vendido
- Produto menos vendido
- Categoria mais vendida
- Limpeza automática do formulário após o cadastro

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript


## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
